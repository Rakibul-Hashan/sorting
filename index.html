Changelog
  • v0.43 – Sounds for every step, on all tabs including Merge Sort. Each number has its own musical note (small = low, big = high, always from one pleasant scale), so you can hear a list get sorted. Compare = the two notes of the numbers being compared; Swap = two notes with a soft knock; Shift / place / bucket = one warm note; a bell rings when a number reaches its final place; a new pass or call = a quiet tick; Done = a short fanfare. Stepping with Next or ◀ and Play all make sound; dragging the slider or jumping stays quiet. Check it: press Play on any tab. Top right: the 🔊 button mutes, and the slider next to it sets the volume (on wider screens). Your choice is remembered.
  • v0.42 – Responsiveness fixes found with a real-browser check of every tab at 320, 360, 390, 768, 1024 and 1366 px wide. (1) On phones the whole page could slide sideways by 150 to 670 px because the stage and code box could not shrink; they now shrink to the screen (this also fixes the Merge Sort tab). (2) The pseudocode block on the Merge Sort tab no longer pushes the page wider on very small phones; long code lines scroll inside their box. (3) Buttons and menus are at least 40 px tall on phones and touch screens, so they are easy to tap. (4) With many numbers on a narrow screen, the number row scrolls sideways, follows the action automatically and shows a “swipe” hint. (5) Pointer labels (i, j, root, key…) are no longer cut off at the edges. (6) The empty gap under the cards at the end of Counting Sort and Radix Sort is gone.
  • v0.41 – New Radix Sort tab (next to Counting Sort). Ten buckets (digits 0 to 9) sit under the cards; every number drops into its bucket by the current digit (underlined), then the buckets are emptied in order, pass after pass: ones, tens, hundreds. Whole numbers 0 to 999; “Random” makes 10 to 199, and the demo list is the classic 170, 45, 75, 90, 802, 24, 2, 66. Check it: click “Radix Sort”, press Play, and use the ⏭ button to jump from pass to pass.
  • v0.40 – New Counting Sort tab (after a divider, because it never compares two numbers). Under the cards you see the count boxes and the output list fill up; the code box shows the three loops (count, running totals, place) as blocks. It accepts whole numbers 0 to 20; other tabs keep working with any numbers. “Random” makes 0 to 9 here. Check it: click “Counting Sort”, press Play, and watch the numbers glide into place at the last step.
  • v0.39 – Tidy-up and improvements for the Bubble, Selection, Insertion, Shell, Quick and Heap tabs (Merge Sort untouched). (1) The tab row is one tidy line that scrolls sideways on small screens, with Merge Sort separated and the others in teaching order. (2) New table under the tab, “Compare all sorts on this list”, with comparisons, moves and steps for every sort; click a name to jump to that sort. (3) New ⏭ button jumps to the next pass or call. (4) New “Share link” button: the page address now remembers the sort and the numbers, so a classmate sees exactly the same animation. (5) Screen readers read each step message. (6) The six sorts now share one helper, so the file is smaller and easier to extend.
  • v0.38 – New Shell Sort tab (seventh tab). The numbers in the same chain as the current key (exactly gap places apart) are outlined in cyan, the key is amber and jumps left by the gap, and the code box shows each gap as a block with one smaller block per i. Check it: click “Shell Sort”, press Play, and watch how the gap goes 4, 2, 1 for 8 numbers.
  • v0.37 – New Heap Sort tab (sixth tab). A heap tree is drawn above the number cards (children of index k are 2k+1 and 2k+2), the largest-so-far is amber, and the code box shows HeapSort and the recursive Heapify, where each call opens as its own copy and calls itself again when a number sinks further. Check it: click “Heap Sort”, press Play, and watch the tree and the cards together.
  • v0.36 – New Insertion Sort tab (fifth tab). The key is amber and slides left while bigger numbers shift right, the sorted part is outlined in cyan, and every pass is its own block in the code box with the while checks written out. Check it: click “Insertion Sort”, press Play, then try “Sorted (best case)”. The counter says “shifts” here.
  • v0.35 – New Selection Sort tab (fourth tab). The smallest number found so far is amber, the compared number j glows, the sorted left part turns green, and each pass is its own block in the code box. Check it: click “Selection Sort”, press Play, and note that “Sorted (still O(n²))” takes just as many comparisons.
  • v0.34 – New Bubble Sort tab (third tab at the top). Each pass opens as its own block in the code box, the compared pair j and j+1 is highlighted, finished passes turn grey, and the swapped flag stops it early on sorted input. Check it: click “Bubble Sort”, press Play, then try “Sorted (best case)”.
  • v0.33 – New Quick Sort tab (top of the page, next to Merge Sort). Same layout: animated numbers with i/j pointers and a pivot, plus the code box with the pseudocode definition (QS and Partition) and the live steps. Check it: click “Quick Sort”, then press Play. “Sorted (worst case)” shows why Quick Sort can become O(n²).
